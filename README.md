# 方块越狱：封锁区

根据参考视频玩法制作的原创体素风 3D 越狱闯关游戏。路线包含牢房区、洗衣房、排污渠、锅炉房、安检走廊、厨房、通风管、操场、屋顶和撤离点。

## 启动

```bash
pnpm install
pnpm dev
```

浏览器打开 `http://127.0.0.1:5173/`。

## 操作

- `WASD` 或方向键移动
- `空格` 跳跃
- 按住并拖动鼠标水平/垂直旋转视角
- 鼠标滚轮调整镜头距离，`C` 将镜头回正到角色背后
- `F`、鼠标点击或触屏攻击键进行近战攻击
- 手机端使用左侧摇杆和右侧跳跃键

游戏包含 10 个越狱场景、可视化检查点信标、计时、死亡复活、像素材质与通关结算。金发 9 号球星守卫会在特定关卡追击玩家；战斗关卡具有敌人血条和封锁闸门，击败守卫后才能继续前进。

其他功能包括暂停菜单、自动画质、移动端低功耗模式、最佳成绩、环境/战斗音效和 PWA 独立启动支持。按 `ESC` 可暂停或继续游戏。

## 测试

```bash
pnpm run audit:levels
pnpm run build
```
